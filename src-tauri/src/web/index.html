GET /health

健康检查，返回服务状态和 WPS 可用性

请求参数：无

响应体：

{ "status": "ok", // 服务状态 "version": "1.0.0", // 应用版本 "wps_available": true, // WPS 是否可用 "wps_prog_id": "KWPS.Application" // WPS ProgID，不可用时为 null }

GET /api/settings

获取应用设置

请求参数：无

响应体：

{ "default_output_dir": "C:\\Users\\xxx\\output" // 默认输出目录，可能为 null }

GET /api/check-wps

检测本机已安装的转换引擎 (WPS / Microsoft Office)

请求参数：无

响应体：

{ "available": true, // 当前引擎是否可用 "version": "12.1.0.16417", // 当前引擎版本号，不可用时为 null "error": null, // 错误信息，正常时为 null "engine": "auto", // 当前选择的引擎: auto / wps / office "engines": [ { "engine": "wps", "available": true, "version": "12.1.0.16417", "error": null }, { "engine": "office", "available": true, "version": "16.0.17000", "error": null } ] }

POST /api/convert

单文件转换为 PDF

Query 参数：

参数类型必填说明
asyncboolean否是否异步模式，默认 false
responsestring否可选 json 或 file，当为 file 时同步返回 PDF 二进制流
enginestring否本次使用的引擎: auto / wps / office。省略则使用桌面端设置中的全局引擎

请求体：multipart/form-data

字段名类型必填说明
fileFile是要转换的文件 (.doc/.docx/.xls/.xlsx)
output_namestring否自定义输出文件名

同步模式响应体：

{ "success": true, "task_id": "uuid-string", "input_file": "document.docx", "output_file": "C:\\...\\document.pdf", // 异步模式为 null "file_size": 123456, // 字节数，异步模式为 null "duration_ms": 2500, // 耗时毫秒，异步模式为 null "message": "转换成功", "error": null }

错误响应体：

{ "success": false, "message": "错误描述" }

当 response=file 时：

Content-Type: application/pdf Content-Disposition: attachment; filename="document.pdf" (PDF 二进制数据)

POST /api/convert-batch

批量文件转换（同一类型: 全部 Word 或全部 Excel）

Query 参数：

参数类型必填说明
asyncboolean否是否异步模式，默认 false
responsestring否可选 json 或 file，当为 file 时同步返回 PDF 二进制流
enginestring否本次使用的引擎: auto / wps / office。省略则使用桌面端设置中的全局引擎

请求体：multipart/form-data

字段名类型必填说明
files 或 files[]File (多个)是要转换的文件列表
output_folderstring否输出目录绝对路径

同步模式响应体：

{ "success": true, "task_id": "uuid-string", "total": 3, "succeeded": 3, "failed": 0, "duration_ms": null, "results": [ { "file": "doc1.docx", "status": "success", // "success" 或 "failed" "output": "C:\\...\\doc1.pdf", "size": 12345, "duration_ms": 2000, "error": null } ], "message": "转换完成" }

POST /api/convert-from-url

通过文档下载链接先下载，再转换为 PDF

Query 参数：

参数类型必填说明
asyncboolean否是否异步模式，默认 false
enginestring否本次使用的引擎: auto / wps / office。省略则使用桌面端设置中的全局引擎

请求体：application/json

{ "url": "https://example.com/demo.docx", "output_name": "demo.pdf", // 可选 "output_folder": "C:\\output" // 可选，需绝对路径 }

响应体：

{ "success": true, "task_id": "uuid-string", "input_file": "demo.docx", "output_file": "C:\\...\\demo.pdf", "file_size": 123456, "duration_ms": 2500, "message": "下载并转换成功", "error": null }

当 response=file 时：

Content-Type: application/pdf Content-Disposition: attachment; filename="document.pdf" (PDF 二进制数据)

POST /api/convert-batch-from-urls

通过多个文档下载链接先批量下载，再批量转换 PDF

Query 参数：

参数类型必填说明
asyncboolean否是否异步模式，默认 false
enginestring否本次使用的引擎: auto / wps / office。省略则使用桌面端设置中的全局引擎

请求体：application/json

{ "urls": [ "https://example.com/a.docx", "https://example.com/b.docx" ], "output_folder": "C:\\output" // 可选，需绝对路径 }

响应体：

{ "success": true, "task_id": "uuid-string", "total": 2, "succeeded": 2, "failed": 0, "duration_ms": null, "results": [ { "file": "a.docx", "status": "success", "output": "C:\\...\\a.pdf", "size": 12345, "duration_ms": 2000, "error": null } ], "message": "下载并批量转换完成" }

GET /api/status/:task_id

查询异步任务进度

路径参数：

参数类型说明
task_idUUID string转换任务返回的 task_id

响应体：

{ "task_id": "uuid-string", "status": "pending|processing|completed|failed", "progress": 75, // 进度百分比 0-100 "current_file": "document.docx", // 当前处理文件，可为 null "total_files": 4, "completed_files": 3, "results": [ // 完成后才有，处理中为 null { "file": "doc1.docx", "status": "success", "output": "C:\\...\\doc1.pdf", "size": 12345, "duration_ms": 2000, "error": null } ], "error": null, // 失败时的错误信息 "started_at": "2026-03-24T10:30:00+08:00" }

GET /api/preview

预览转换后的 PDF 文件（返回 PDF 二进制流）

Query 参数：

参数类型必填说明
pathstring是PDF 文件绝对路径（需 URL 编码）

成功响应：

Content-Type: application/pdf Content-Disposition: inline; filename="document.pdf" (PDF 二进制数据)

错误响应 (JSON)：

{ "success": false, "message": "无法读取文件: ..." }

GET /api/update/check

检查版本更新

请求参数：无

响应体：

{ "success": true, "current_version": "1.0.0", "latest_version": "1.1.0", // 可为 null "update_available": true, "download_url": "http://...", // 可为 null "notes": "Bug fixes", // 更新说明，可为 null "pub_date": "2026-03-20", // 发布日期，可为 null "error": null }

POST /api/update/install

下载更新清单中的安装包。就绪后调用 /api/update/launch 启动安装。

请求体：application/json

{ "url": "https://example.com/update.exe" // 必须等于检查更新返回的 download_url }

响应体：

{ "success": true, "message": "已开始下载" }
